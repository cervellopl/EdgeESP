EdgeESP companion

Weather pushed to the device

Web Bluetooth works in Chrome and Edge on Android, Windows, macOS and Linux. iOS needs a browser with Web Bluetooth support (for example Bluefy), or a native app.

Weather comes from open-meteo.com — no account or API key needed. Fetching it sends your coordinates to that service, taken from the device's GPS, or from this browser if there is no fix yet. Nothing else leaves this page. If you would rather not, simply do not press Refresh weather; every other feature works without it.
